============================================================
PART 1 — Make endpoint path encoding explicit
============================================================

ControllerEndpointBuilder currently has:

- httpURL(path:queryItems:)
- websocketURL(path:queryItems:)
- composeURL(baseURL:path:queryItems:)

Keep these APIs for static literal paths such as:

- "/configs"
- "/memory"
- "/providers/proxies"
- "/providers/rules"
- "/dns/query"
- "/cache/dns/flush"
- "/restart"

But add raw path-component APIs for dynamic endpoints:

static func httpURL(pathComponents: [String], queryItems: [URLQueryItem] = []) throws -> URL
static func websocketURL(pathComponents: [String], queryItems: [URLQueryItem] = []) throws -> URL

The pathComponents API must:

- Treat every element as one raw path component.
- Percent-encode each component exactly once.
- Preserve slashes inside a dynamic component by encoding them as %2F, not by splitting the component into multiple path levels.
- Support spaces, Chinese characters, emoji, percent signs, and slash-containing names.
- Not double-encode already percent-like raw names unless the raw name literally contains a percent character and should be represented as %25.

For static path strings, keep path string APIs simple and only use them for endpoints that are known compile-time literal paths. The path string API may continue to split on "/". Do not use it for dynamic proxy/group/provider/config names.

Implementation guidance:

- Prefer URLComponents percentEncodedPath construction for explicit control.
- Alternatively use appendingPathComponent only for raw components and never feed pre-encoded strings into it.
- Avoid mixing "already encoded string" and "raw component" semantics.

Add comments in ControllerEndpointBuilder explaining the distinction:

- path: for static literal endpoint paths
- pathComponents: for dynamic endpoint paths with raw names

PART 2 — Update dynamic ApiRequest call sites
============================================================

Search for `.encoded` in ApiRequest and related controller request files.

Convert dynamic endpoints to pathComponents.

At minimum update:

- updateProxyGroup(group:selectProxy:)
  Old pattern:
  "/proxies/\(group.encoded)"

  New pattern:
  pathComponents: ["proxies", group]

- getProxyDelay(proxyName:)
  Old pattern:
  "/proxies/\(proxyName.encoded)/delay"

  New pattern:
  pathComponents: ["proxies", proxyName, "delay"]

- healthCheck(proxy:)
  Old pattern:
  "/providers/proxies/\(proxy.encoded)/healthcheck"

  New pattern:
  pathComponents: ["providers", "proxies", proxy, "healthcheck"]

- healthCheckProvider(proxy:)
  Same as above.

- updateProviderResult(name:type:)
  For proxy providers:
  pathComponents: ["providers", "proxies", name]
  For rule providers:
  pathComponents: ["providers", "rules", name]

- requestPolicyGroup(name:)
  pathComponents: ["group", name]

- deletePolicyGroup(name:)
  pathComponents: ["group", name]

- requestPolicyGroupDelay(name:)
  pathComponents: ["group", name, "delay"]

- requestSmartWeights(group:)
  pathComponents: ["group", group, "weights"]

- flushSmartCache(configName:)
  If configName exists:
  pathComponents: ["cache", "smart", "flush", configName]
  Else static path "/cache/smart/flush"

- blockSmartConnection(id:)
  pathComponents: ["connections", "smart", id]

Also check non-ApiRequest files:

- ConnectionsReq and StructedLogReq can keep literal static paths.
- Any request that interpolates a dynamic identifier into a string path should use pathComponents.
- Do not pass `.encoded` into pathComponents.
- If `.encoded` is still needed elsewhere outside controller endpoints, leave it alone.

If a dynamic identifier may already be encoded by old code, prefer passing the raw model value. Do not decode and re-encode unless you can prove the value is encoded.

PART 4 — Add smoke tests for encoding
============================================================

Update Tests/SecurityHarness/controller_endpoint_builder_smoke.swift.

Add cases that would fail with double encoding:

1. Raw component with space:
   pathComponents ["proxies", "Proxy A"]
   expected URL contains "Proxy%20A"
   expected URL does NOT contain "%2520"

2. Raw component with Chinese characters:
   pathComponents ["group", "香港 节点"]
   expected URL contains percent-encoded UTF-8
   expected URL does NOT contain "%25E9" caused by double encoding

3. Raw component with slash:
   pathComponents ["providers", "proxies", "Group/A"]
   expected URL encodes slash as "Group%2FA" or equivalent, not as separate path segments "Group/A"

4. Raw component with literal percent:
   pathComponents ["proxies", "50% Node"]
   expected URL represents the percent as "%25"
   This is correct because the raw name contains a literal percent.

6. Add a regression test for the exact review case:
   If input dynamic raw component is "Proxy A", it should produce ".../Proxy%20A", never ".../Proxy%2520A".
