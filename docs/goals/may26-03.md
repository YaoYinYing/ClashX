TASK 1: Sanitize DiagnosticsArtifactFormatter config preview
============================================================

Problem:

DiagnosticsReportBuilder.build() already calls SmartXRedactor.sanitizeText(report), so copied reports are safer.

However, DiagnosticsArtifactFormatter.formatArtifactPreview() reads the first 20 lines of saved config artifacts and displays them in the Diagnostics Dashboard. That preview is currently not guaranteed to pass through SmartXRedactor.sanitizeText().

This can leak:

- proxy URIs
- subscription URLs
- token-bearing URLs
- external-controller-secret
- Authorization-like values
- proxy credentials
- local home paths

This is the only current merge-blocking issue.

Required change:

1. In DiagnosticsArtifactFormatter, sanitize the preview before appending it to the output.

Current shape is likely similar to:

let preview = (try? String(contentsOf: configURL, encoding: .utf8))
    .map { previewText(from: $0, maxLines: 20) }
    ?? NSLocalizedString("Config preview could not be read.", comment: "")

Change it so that preview text goes through:

SmartXRedactor.sanitizeText(...)

For example:

let preview = (try? String(contentsOf: configURL, encoding: .utf8))
    .map { SmartXRedactor.sanitizeText(previewText(from: $0, maxLines: 20)) }
    ?? NSLocalizedString("Config preview could not be read.", comment: "")

or sanitize inside previewText(from:maxLines:).

2. Keep the preview useful but safe.
   It is acceptable if sanitized output is less detailed.

3. Do not remove artifact preview entirely unless sanitization is unexpectedly difficult.

Acceptance criteria:

- Artifact preview does not display raw proxy URIs.
- Artifact preview does not display token-bearing URLs.
- Artifact preview does not display raw Authorization-style values.
- Artifact preview redacts home directory paths.
- DiagnosticsArtifactFormatter uses SmartXRedactor.sanitizeText() or equivalent.
