2. Check:
   - ClashX.xcworkspace exists as a directory.
   - ClashX.xcworkspace/contents.xcworkspacedata exists and is non-empty.
   - contents.xcworkspacedata parses as XML.

     bundle install
     bundle exec pod install

5. Support optional repair mode:

   SMARTX_ENSURE_WORKSPACE_REPAIR=1 scripts/ensure-xcworkspace.sh

   In repair mode:
   - If Gemfile exists, run bundle install if needed.
   - Run bundle exec pod install.
   - Re-run the workspace checks.
   - Do not rm -rf Pods or Podfile.lock by default.
   - Only print destructive repair suggestions; do not delete by default.

6. Support optional destructive regeneration only when explicitly requested:

   SMARTX_REGENERATE_WORKSPACE=1 scripts/ensure-xcworkspace.sh

   In this mode:
   - Remove ClashX.xcworkspace and Pods.
   - Do NOT remove Podfile.lock unless SMARTX_REGENERATE_PODFILE_LOCK=1 is also set.
   - Run bundle install.
   - Run bundle exec pod install.
   - Re-run validation.

7. Exit codes:
   - 0: workspace ready.
   - 1: workspace invalid or dependencies missing.
   - 2: repair attempted but still invalid.

8. Output should be concise but actionable.
