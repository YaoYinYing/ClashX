Discussion summary to incorporate:
We have discussed that SmartX should not overcomplicate the product by exposing core differences to users. The main user path should remain a bundled release with an embedded Smart core. Smart-specific features should be enabled only when runtime capability probes show that the current controller/core supports them. If SmartX has to run against ordinary mihomo later, these features should be disabled or hidden without breaking normal mihomo functionality.
